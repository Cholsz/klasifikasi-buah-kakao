# Sistem Klasifikasi Penyakit Buah Kakao CNN Berbasis Web

Aplikasi web klasifikasi citra penyakit buah kakao menggunakan kerangka kerja Flask (Python) dan model Convolutional Neural Network (CNN) Keras (.keras).

## Klasifikasi Kelas:
1. Black Pod Rot (Busuk Buah Hitam)
2. Healthy (Sehat)
3. Pod Borer (Penggerek Buah Kakao)
